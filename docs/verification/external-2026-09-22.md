## 额外专项验证

- 预先创建的禁用 AD-only 专用测试用户：入职返回 409，未被转成邮箱用户。
- 负数/非数字/冲突 Content-Length：400；超大请求头：431；单个未完成请求空闲约 15.33 秒后关闭，服务仍正常。
- 外部请求执行期间停服：请求完整返回 200，约 3.54 秒后停止，待核查记录清理；重启后外部健康接口正常。
- 对不存在的专用测试账号，人工创建带明确测试标记的 `.pending`：请求返回 409 `OPERATION_STATE_UNKNOWN`；服务真实重启后仍拒绝。停服后单独归档该测试记录，再启动，正常返回账号不存在 404。该测试验证记录恢复，不冒充断电或真实写入超时验收。
- 日志字段检查无密码值字段，不包含服务账号密码；记录请求 ID、账号和时间。`initial_password` 可能出现在固定的“缺少密码”错误说明中，这不是密码泄露。

超大请求体/请求头等在 Waitress 层拒绝，错误响应可能为非 JSON、无应用请求 ID；调用方应先判断 HTTP 状态和 Content-Type，不能无条件按 JSON 解析。
